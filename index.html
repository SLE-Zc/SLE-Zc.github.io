SRE第一次作业(有图有真相version)

——Submitted by Zc

作业：

  • 在 Linux 上用 vim 写一段 C 语言代码输出 hello, world RedRock(doge)

命令(Commands):

vim Hello.c 创建并编辑Hello.c
i 进入insert状态

esc 返回普通状态
:wq 保存
gcc Hello.c -o Hello 把Hello编译为机器语言
./Hello 执行Hello.c
**(终端输出：Hello，RedRock!) 大功告成

  • 了解 Typora 或 Obsidian 的使用，会写简单的 Markdown 文件
  • 给自己的虚拟机上面配置好常用的环境，如 Python、Java、gcc 等(Kali上都预装好了的)
  • 搭建一个个人博客网站 让我康康.jpg
